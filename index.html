MRS Engineering - User Link Sharing

Private Link Sharing

A link can only work on another phone when the MRS Engineering app file is stored at an online/private share location such as Google Drive, OneDrive, Dropbox, or your company website. The content://downloads/... address on your phone is not a shareable link.

Recommended private method

  1. Upload the MRS Engineering HTML file to Google Drive or another private storage.
  2. Set access to the authorized users only.
  3. Copy the file's sharing link.
  4. Paste the link above.
  5. Select the user and share through WhatsApp/Email.

Security: Do not put passwords inside the link. Send login credentials separately.

Users, Rights & Sharing

Share App

Use Android Share to send the app file through WhatsApp, Email, Drive, etc. Each user logs in with their own account. For one common database across all phones, a cloud/server version is required.

Admin: full access. Manager: jobs, raw material, process and export. Operator: view dashboard/tracking only. Share this HTML file with authorized users. Each device has separate local data; common synchronized data needs a cloud database.
